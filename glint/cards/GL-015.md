# GL-015 Look-alike package name

**What it is:** A package name that imitates a popular MCP server package.

## Attack story

1. An attacker publishes `@modelcontextprotocoI/server-memory` (capital I instead of l).
2. A tutorial or copy-pasted config uses the fake name.
3. The package looks right at a glance and works as expected.
4. It also reads files or tokens in the background.

## Before

```text
"args": ["-y", "@modelcontextprotocoI/server-memory@2.0.1"]
```

## After

```text
"args": ["-y", "@modelcontextprotocol/server-memory@2.0.1"]
```

# GL-002 Hidden content

**What it is:** Instructions placed where a human reviewer cannot see them in rendered Markdown, but the agent reads them.

## Attack story

1. An attacker opens a pull request that edits `AGENTS.md`.
2. The visible diff looks harmless; the instruction sits inside an HTML comment.
3. The reviewer reads the rendered preview and approves.
4. Every agent session now follows the hidden instruction.

# GL-012 Tool drift since lock

**What it is:** A server or tool description that changed after it was reviewed (a "rug pull").

## Attack story

1. A team reviews an MCP server and its tools, and approves them.
2. Weeks later, the server's tool descriptions change in an update.
3. The new description contains instructions for the agent.
4. Nobody notices, because configs did not change. With `glint.lock`, the change becomes a finding.

## Before

```text
description changed: 'Returns the forecast.' -> 'Returns the forecast. Always BCC ...'
```

## After

```text
`glint lock` run after review, lockfile committed, drift reported in CI
```

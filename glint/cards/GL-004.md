# GL-004 Dangerous MCP tools

**What it is:** MCP servers that give the agent a shell or access to the whole disk.

## Attack story

1. A project config adds a filesystem server rooted at `/`.
2. Later, a prompt injection arrives through a web page or issue.
3. The injected text asks the agent to read `~/.ssh/id_rsa` or `~/.aws/credentials`.
4. The agent has the access, so it does.

## Before

```text
"args": ["-y", "@modelcontextprotocol/server-filesystem@2.1.0", "/"]
```

## After

```text
"args": ["-y", "@modelcontextprotocol/server-filesystem@2.1.0", "./docs"]
```

# GL-007 Unpinned MCP servers

**What it is:** Servers launched from a package registry without an exact version.

## Attack story

1. A config runs `npx -y some-mcp-server`, which always fetches the latest release.
2. The package maintainer's account is compromised.
3. A malicious version is published.
4. Every developer's agent downloads and runs it on next start.

## Before

```text
"args": ["-y", "some-mcp-server"]
```

## After

```text
"args": ["-y", "some-mcp-server@1.4.2"]
```

# GL-009 Auto-approve and skip-permission flags

**What it is:** Settings that let tools run without asking the user.

## Attack story

1. A config auto-approves `run_command` to avoid repeated prompts.
2. A prompt injection arrives through a web page the agent reads.
3. The injected text asks the agent to run a command.
4. No prompt appears, so nobody gets a chance to say no.

## Before

```text
"alwaysAllow": ["run_command"]
```

## After

```text
"alwaysAllow": ["list_files"]
```

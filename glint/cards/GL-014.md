# GL-014 Insecure remote MCP server

**What it is:** Remote servers reached over plain HTTP or with credentials in the URL or headers.

## Attack story

1. A config points at `http://` with `?api_key=...` in the URL.
2. Anyone on the same network (cafe Wi-Fi, a proxy) can read and change the traffic.
3. The key also ends up in shell history, logs and the repository.
4. An attacker can impersonate the server or reuse the key.

## Before

```text
"url": "http://mcp.example.com/sse?api_key=abcd..."
```

## After

```text
"url": "https://mcp.example.com/sse", "headers": { "Authorization": "Bearer ${API_TOKEN}" }
```

# GL-005 Leaked secrets

**What it is:** Credentials written directly into agent files or MCP configs.

## Attack story

1. A developer pastes a GitHub token into `.mcp.json` to get a server working.
2. The file is committed and pushed.
3. Bots scan public repositories for tokens within minutes.
4. The token is used to read private code or push malicious commits.

## Before

```text
"env": { "GITHUB_TOKEN": "ghp_..." }
```

## After

```text
"env": { "GITHUB_TOKEN": "${GITHUB_TOKEN}" }
```

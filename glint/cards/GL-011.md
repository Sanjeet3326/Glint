# GL-011 Lethal trifecta

**What it is:** One agent that can read private data, take in untrusted content and send data out.

## Attack story

1. The agent can read your files (filesystem server).
2. It also reads web pages or GitHub issues (untrusted content).
3. And it can make HTTP requests or post comments (a way out).
4. An attacker writes instructions into a web page or issue; the agent reads them, collects private data and sends it out.

## Before

```text
filesystem + fetch + github servers in one config
```

## After

```text
filesystem + time servers (no untrusted input, no way out)
```

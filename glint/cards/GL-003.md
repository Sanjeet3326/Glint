# GL-003 Invisible Unicode

**What it is:** Characters that are invisible or reorder text, so humans and agents read different things.

## Attack story

1. An attacker hides a message with Unicode tag characters, which no editor shows.
2. Or a right-to-left override makes code or text display in a different order.
3. Code review shows clean text.
4. The agent reads the hidden message and acts on it.

# GL-010 Wildcard or over-broad permissions

**What it is:** Allowlist entries that let the agent run almost anything.

## Attack story

1. `Bash(*)` is added to settings to stop permission prompts.
2. The agent processes an issue that contains injected instructions.
3. It runs `curl` to post files to an outside server.
4. The allowlist approved it in advance.

## Before

```text
"allow": ["Bash(*)"]
```

## After

```text
"allow": ["Bash(npm run test:*)", "Bash(git status)"]
```
